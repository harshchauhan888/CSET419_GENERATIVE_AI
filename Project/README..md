# 📄 CSET 419 Project: DocuMind AI – RAG-Based PDF Chatbot

## 📌 Description
DocuMind AI is an intelligent chatbot that allows users to upload PDF documents and ask questions from them.  
It uses Retrieval-Augmented Generation (RAG) to provide accurate, context-based answers instead of guessing.

---

## ✨ Features
- Upload one or multiple PDF files  
- Ask questions in simple language  
- Get answers directly from documents  
- AI-powered accurate responses  
- Clean and user-friendly interface  

---

## 🛠 Tech Stack
- Python  
- Streamlit  
- LangChain  
- OpenAI API / Gemini  
- FAISS / ChromaDB  
- PyPDF2 / pdfplumber  

---

## ⚙️ Installation

1. Clone the repository:
git clone https://github.com/harshchauhan888/CSET419_GENERATIVE_AI/tree/main/Project

2. Go to project folder:
cd documind-ai  

3. Install dependencies:
pip install -r requirements.txt  

4. Add API key in .env file:
OPENAI_API_KEY=your_api_key_here  

5. Run the app:
streamlit run app.py  

---

## ▶️ Usage
- Upload PDF documents  
- Type your question in chat  
- Get answers based on document content
